# 轻笺 · LightNote

精简的 Windows 11 本地便笺与日期提醒工具。

界面采用紧凑桌面布局：默认 580×430、148 宽便笺列表、单行提醒与置顶工具栏、底部单行保存状态。支持缩小至 500×340。编辑区直接呈现标题和正文，保留键盘导航、右键删除和所有原有功能。

![轻笺图标](source/app.png)

## 使用

下载仓库或克隆到本机后，双击根目录的 **LightNote.exe**。请保留同目录的 **LightNote.exe.config**。

- 左侧便笺列表显示标题与正文摘要，点击切换，右键删除。
- 标题和正文自动保存，删除的便笺可恢复。
- 每张便笺可独立置顶，记住窗口位置和大小。
- 日历选择日期与时间，到时弹窗并可播放声音，支持延后 10 分钟。
- 托盘常驻，关闭或最小化窗口后仍运行；托盘右键可完全退出。
- 更多菜单可切换开机启动、提示音、便笺色条，或导出文本。
- 数据完全保存在本机，无账号、无联网。

开机启动默认关闭。电脑关机、休眠或程序退出期间无法即时提醒，恢复运行后会补报。

详细操作、快捷键、数据备份和提醒边界见 [使用说明](使用说明.md)。

## 构建

原生 C# / WPF，使用 Windows Forms 托盘和 Windows 11 自带的 .NET Framework 4.8 系列，无第三方运行时依赖。

在仓库根目录运行：

```powershell
.\source\build.ps1
```

构建使用 Windows 自带 C# 编译器，将程序输出到仓库根目录。图标资源已包含在源码中；仅重新生成图标时需要 Python 与 Pillow。

## 验证

```powershell
.\LightNote.exe --self-test --data-dir "$env:TEMP\LightNote-Tests"
Get-Content "$env:TEMP\LightNote-Tests\test-results.txt"
```

13 项自动检查覆盖保存恢复、原子替换、备份、损坏保护、提醒状态和回收站。左侧列表与右键菜单已在当前 Windows 11 环境打开验证。

新版使用软件渲染，避免部分显卡驱动或远程桌面环境中的 WPF 白屏。已有便笺首次升级时切换为紧凑窗口尺寸，此后继续记住用户调整后的大小和位置。

## 数据

正式便笺位于 `%LOCALAPPDATA%\LightNote`，不属于仓库内容。仓库只包含程序、源码、图标和说明。

本版本未加入云同步、富文本、重复提醒或多张便笺同时显示。
